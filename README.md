# 🧠 LotoFácil IA v7.0

Sistema autônomo de análise da Lotofácil com:
- 14 motores analíticos internos
- 15 oráculos convergentes independentes
- Ciclo fechado: Geração → Conferência → Aprendizado
- Cartela do Dia por consenso emergente

## 🚀 Rodar

```bash
pip install -r requirements.txt
python app.py
```

Acesse: `http://localhost:5000`

## 📋 Módulos

- **Cérebro IA** — 14 motores (Markov, Verlet, Quantum, Bayes...)
- **Oráculo Convergente** — 15 teorias independentes votam
- **Cartela do Dia** — 1 cartela por consenso emergente
- **Conferência** — Automática via API da Caixa
- **Auditoria** — Transparência total das decisões

## 🎯 Uso

1. Acesse `/cerebro` → **Treinar Cérebro**
2. Acesse `/cartela_do_dia` → Gerar cartela única
3. Depois do sorteio: `/conferencia` → Conferir
